# KINO 報價與合約工具

奇諾影像使用的瀏覽器版報價、合約與簽署文件產生工具。目前部署於 GitHub Pages：

- <https://aaronkino.github.io/qt/>

## 報價分類

### 快速報價

- 適合一般專案與初步報價。
- 輸出摘要、合約條款、付款條件及簽署欄。
- 使用獨立的單張 A4 單欄文件流，不輸出服務細項表；專案概況與甲乙方簽署區採等寬雙欄。
- 甲乙方欄位固定等寬，簽署列預留 1.8 cm 簽章空間。
- 每個報價摘要可選填數量與單位（例如 `1 案`、`4 天`、`2 支`）；未填則不顯示內容。
- 條款維持約 8–9pt 可讀字級，不再用 50% 整頁縮放塞入單頁。

### 詳細報價

- 適合高單價或需要逐項說明的專案。
- 第一頁沿用快速報價的 A4 摘要、條款、付款與簽署格式。
- 第二頁起列出完整服務項目、數量、單位、單價與小計。

舊版 JSON 開啟時會依原本的 `showDetails` 設定自動轉換。新版資料使用 `schemaVersion: 3` 與 `quotationType: "quick" | "detailed"`。

## 使用方式

1. 直接開啟線上工具。
2. 選擇「快速報價」或「詳細報價」。
3. 填寫專案、金額、條款與簽署資料。
4. 以「本機專案庫 → 存專案」儲存完整專案快照，日後可從同一選單載入；也可使用「另存」下載專案 JSON 備份。
5. 付款方式可選擇三期 `40 / 30 / 30`、兩期 `50 / 50` 或全額付款範本。
6. 簽署區可填寫甲乙方資料，以手寫方式簽名或上傳簽名／印章圖片。
7. 要提供甲方填寫時，使用「甲方可填寫 PDF」：甲乙方基本資料會是 PDF 表單欄位，簽章列會是標準 PDF 簽名欄。
8. 使用「一般 PDF」時，開啟瀏覽器列印介面，目的地選擇 PDF。

快速報價在手機與電腦都會輸出相同的專用 A4 版型；列印縮放請保持 100%。若自行新增大量條款，內容超過一頁時應改用「詳細報價」，避免犧牲字級。

介面會依螢幕寬度自動切換工作區：手機使用卡片式編輯，平板與電腦使用 A4 文件式編輯，不需要手動選擇 Desktop／Mobile。畫面頂端會持續顯示目前報價模式及其 PDF 輸出規則。

目前不需要 npm；主程式仍是可直接部署的靜態 `index.html`。後續會逐步改為模組化 React 專案。

## 資料與保密

這是公開程式庫，任何提交到 GitHub 的內容都可能被所有人讀取。請勿提交：

- 真實客戶名稱、聯絡方式、報價與未公開專案內容。
- 客戶或公司簽名圖片。
- 匯出的專案 JSON 或正式合約 PDF。
- Google、Microsoft、GitHub、Cloudflare 的 token、API key 或 OAuth secret。

目前草稿、自訂條款範本與「本機專案庫」都存在使用者自己的瀏覽器 `localStorage`；專案庫只會保存在目前瀏覽器與裝置。另存的 JSON 只會放在使用者選擇的本機位置，不會自動上傳 GitHub。手寫簽名或上傳的印章也會一併保存在目前專案資料中。

「甲方可填寫 PDF」由獨立的 Cloudflare Worker 即時產生：它只處理當次請求並回傳 PDF，不設資料庫或檔案保存。甲方應以 Adobe Acrobat Reader 或其他支援 AcroForm／簽名欄的 PDF 閱讀器填寫；若需上傳印章圖片，可使用 Acrobat 的 Fill & Sign 功能放入簽章欄。

本機專案庫適合日常切換專案，但清除瀏覽器網站資料或換裝置後會消失；重要專案仍應使用「另存」下載 JSON 備份。

## 條款範本

- 「專案合約細節」提供 KINO 標準影音條款，以及「套用條款範本／存為範本」控制項。
- 使用者存下的自訂條款範本只保存在目前瀏覽器；套用範本會取代當前專案的條款，但不會改動付款、報價或客戶資料。

未來雲端整合會採獨立服務：專案資料存放於 Google Drive 或 OneDrive；GitHub 只保存程式與不含客戶資料的共用範本。Cloudflare 服務也會使用獨立 Worker、獨立 secrets 與獨立部署設定，不與官方網站共用。

## 專案結構

- `index.html`：目前正式報價工具。
- `.github/workflows/static.yml`：GitHub Pages 部署流程。
- `rwd/`、`web/`：早期版本，僅供參考。
- `pdf/`：獨立 PDF 小工具，並非正式報價輸出程式。
- `pdf-worker/`：獨立 Cloudflare Worker，產生可填寫 PDF，不與 GitHub Pages 或官網服務共用資料。
