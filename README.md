# KINO Studio 報價工具

公開網站：<https://aaronkino.github.io/qt/>

這是可直接部署到 GitHub Pages 的靜態報價工具，不需要 npm。

## 報價模式

- 快速報價：輸出摘要、條款、付款條件與簽署欄的單頁報價。
- 詳細報價：第一頁沿用快速報價格式，後續頁面列出服務細項。

### 詳細報價預設細項

- 前期：包含「製片統籌與專案管理（行政庶務及後勤費用）」。
- 器材：包含「專業空拍無人機租賃（Hasselblad 6K 或 同級）」。
- 舊版草稿第一次載入時會升級一次並補入這兩個零元預設細項；升級完成後仍可自行刪除。

## 使用方式

1. 填寫報價單號、日期、有效期限與專案概況。
2. 選擇快速報價或詳細報價。
3. 視需要套用付款比例，或開啟「選擇條款」依分類勾選條款。
4. 使用「列印／另存 PDF」，在瀏覽器列印視窗選擇儲存為 PDF。

草稿會持續儲存在目前瀏覽器的 `localStorage`。完整專案與條款資料庫可使用「雲端同步」備份至 KINO 專用 Cloudflare D1，第一次同步需要輸入同步金鑰；金鑰只保留於目前瀏覽器工作階段。

## 資料庫管理

電腦版與手機版上方都有「資料庫管理」入口：

- 專案：以目前報價內容新增專案、載入、改名與刪除。
- 條款資料庫：每條條款可設定分類與「基本／一般／嚴格」程度，並可個別新增、修改或刪除。
- 「完整專案」保存客戶資料、金額、服務細項、付款、已選條款與簽署設定；「條款資料庫」只保存可跨專案重複選用的單條合約文字。
- 原始六條以固定核心序號保存；POP 的「原始預設」頁籤永遠依原始第 1–6 條顯示，不會被分類排序打亂。
- 「智慧財產權」與「檔案保存」分類依嚴謹程度排列；從 POP 勾選匯入時會略過目前報價中完全相同的文字。
- 未連線時仍可在本機操作；刪除項目會保留待同步記錄，恢復連線後再從 D1 刪除。

## 雲端資料庫

- D1：`kino-quotation-data`
- Worker：`kino-quotation-data-api`
- API：<https://kino-quotation-data-api.film-kinostudio.workers.dev>
- 程式與 migration：`cloud-sync/`

同步流程會先檢查 D1 的工作區是否已初始化條款資料庫，避免新裝置把已刪除的預設條款重新寫回；之後再同步完整專案、單條條款與待刪除記錄。日常儲存專案或條款時，若該次瀏覽器工作階段已完成驗證，也會同步更新雲端版本。

第一次使用可由前端以 Web Crypto 產生高強度同步金鑰；API 只使用金鑰的 SHA-256 雜湊分隔資料空間，不保存明文。請將金鑰存入密碼管理器，並在其他裝置輸入同一把金鑰。金鑰不得寫入 `index.html`、GitHub 或其他公開檔案。

## 雲端硬碟規劃

Cloudflare D1 是目前的工作資料庫與跨裝置同步來源。建議將登入、工作資料與專案檔案分工：

- Google 登入：作為手機快速登入方式，不等於必須使用 Google Drive 儲存。
- D1：保存網站中正在編輯的完整專案與條款資料庫，作為跨裝置工作版本。
- OneDrive：維持既有每個客戶／專案資料夾結構，保存定稿 JSON、PDF、試算表與其他製作檔案；電腦端繼續由 OneDrive 同步程式同步。
- Google Drive：如有需要，只做手動備份或分享，不與 OneDrive 同時自動維護同一份 JSON，避免版本衝突。
- OAuth 回呼、用戶端密鑰與更新權杖必須由專用 Worker 處理，不可放在公開 GitHub Pages 前端。

後續優先順序為 Google 帳號登入、D1 使用者工作區綁定，再加入「歸檔至 OneDrive 專案資料夾」。Google Cloud 與 Microsoft Entra 都需要先建立各自的 OAuth 應用程式並設定正式回呼網址。

## 資料安全

未啟用雲端同步時，報價資料不會離開瀏覽器。啟用同步後，已儲存專案及條款資料庫會傳送至專用 D1；API 僅允許本網站來源並要求同步金鑰。請勿將 API 金鑰、帳密或其他無關敏感資訊寫入報價內容。
